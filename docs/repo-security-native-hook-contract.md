# repo-security 原生 hook 契约（M1）

2026-11-20，在 Linux x64 / WSL2 上验证 Git 2.53.0、2.54.0 和 2.56.1。
本记录固定后续安装器实现的边界；消费方接入与原生 macOS 验收另行记录。

## 版本与能力

- 最低 Git 版本为 2.54.0。旧版、缺失或无法识别的版本必须在配置、锁、下载和环境创建之前拒绝。
- 使用 `hook.<name>.command` 和 `hook.<name>.event` 注册独立检查，不保留旧 Git 后端。
- 空事件队列的 `git hook list` 返回值不能单独证明事件能力。用进程级具名空命令探针，关闭该进程的传统 hook 路径，再读取 NUL 分隔名称；探针不执行仓库脚本，不写配置。

## 共存与扫描时点

在 Git 2.56.1 的隔离仓库执行真实提交，接入前顺序为
`project → traditional`，接入后为 `project → security → traditional`。
原生安全项失败时提交被阻止、HEAD 不变；Git 仍可能执行其他检查。
新增更晚的原生注册可以排在安全项之后。

因此只在 setup 时把自己的安全主事件追加到管理配置末尾，保留其他检查的相对顺序、字节、权限、启用状态和 hooksPath。
不要求运行时绝对末项。扫描覆盖 hook 被调用时的提交索引，并保留部分提交的 `GIT_INDEX_FILE`；不承诺覆盖后续检查再次暂存的内容。

## 安装职责边界

2026-11-21 用户决定移除旧安装清理与迁移。本工具只安装自身扫描资源并注册原生 pre-commit，不检查其他工具的成员目录，不删除旧入口，不改写 hooksPath，也不生成项目检查适配脚本。
不支持的清单或资源冲突在写入前报告；其他工具继续管理各自的安装与配置。

## 工作树隔离

实测未开启 `extensions.worktreeConfig` 时，linked worktree 的 `git config --worktree` 返回 128。
开启后，工作树配置仅在对应检出可见；linked worktree 的 `.git` 是文件。
安装器应解析真实 Git 管理目录，只在已具备隔离前提时接入；不能静默改变共享扩展、hooksPath 或其他 hook。

## 验证边界

上述调度探针证明 Git 行为，不单独证明安装器或扫描器正确。
后续 M2 包测试覆盖真实 2.53 的四入口零写入、2.54 原生安装、共存及提交索引；候选 wheel 的真实扫描与诊断单独验收。
不以临时仓库结果代替 dsh-plugin 实际接入。本轮平台范围为 Linux。
