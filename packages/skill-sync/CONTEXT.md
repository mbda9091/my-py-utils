# skill-sync

skill-sync 的领域是个人技能的本地纳管与安装。以下术语区分技能归属和技能使用位置。

## Language

**个人技能仓库**：
用户单独维护、存放本人技能真实文件的 Git 仓库，是个人技能内容的归属位置；当前管理范围内只有一个。
_Avoid_：缓存仓库、技能使用目录

**技能使用目录**：
客户端发现和使用技能的位置，可以同时容纳个人技能与其他来源的技能。
_Avoid_：个人技能仓库

**已纳管技能**：
真实内容归属于个人技能仓库的技能。是否已提交到 Git 不改变其纳管归属。
_Avoid_：已发布技能

**纳管**：
将用户明确选择的已有技能归入个人技能仓库，并保留原有使用入口的行为。
_Avoid_：发布、提交

**安装**：
为个人技能仓库内已有的技能建立客户端使用入口的行为。
_Avoid_：发布、同步仓库

**安装记录**：
某个技能使用入口与其所属个人技能之间关系的本机记录。
_Avoid_：技能清单、版本锁定
